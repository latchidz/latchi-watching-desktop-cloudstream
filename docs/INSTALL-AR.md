# تثبيت LATCHI WATCHING — Windows x64

## المتطلبات
- Windows 10 أو Windows 11 بنواة 64 بت؛ البناء الآلي يُختبر على Windows Server 2022.
- اتصال بالإنترنت للمصادر والإضافات. Qt وJava ومكتبات الفيديو موجودة داخل الحزمة.
- هذا تطبيق Qt أصلي؛ ليس WebView أو Electron ولا يحتاج WebView2.

## اختيار الحزمة
- `LATCHI-WATCHING-1.0.0-Windows-x64-Setup.exe`: مثبّت لحساب Windows الحالي، دون طلب صلاحية مدير النظام.
- `LATCHI-WATCHING-1.0.0-Windows-x64.zip`: فك **كل** الملفات أولًا، ثم شغّل `latchi-watching.exe` من مجلد `LATCHI-WATCHING`.
- ملفات `source` و`Sources` و`metadata` مصادر وتراخيص لإعادة البناء، وليست تطبيقات للتشغيل.

المثبّت غير موقّع رقميًا. قد يظهر تحذير ناشر غير معروف. تحقّق من مصدر التنزيل
وبصمة SHA-256 قبل اتخاذ قرار التثبيت؛ لا تعطّل مضاد الفيروسات أو حماية Windows.

مثال PowerShell للتحقق:

```powershell
Get-FileHash .\LATCHI-WATCHING-1.0.0-Windows-x64-Setup.exe -Algorithm SHA256
```

قارن النتيجة بالسطر الموافق في `SHA256SUMS.txt` المنشور مع الإصدار.

## بدء الاستخدام
1. الصفحة الأولى تفتح مباشرة على بطاقات المصادر الثمانية.
2. اختر مصدرًا. إذا لم تكن إضافته مثبتة، ستظهر موافقة واضحة قبل تنزيل كود طرف ثالث.
3. يتحقق التطبيق من البصمة، ويحوّل حزمة `.cs3` إلى JVM ويختبر تسجيل موفّرها.
4. بعد النجاح يُفتح كتالوغ المصدر. اختر فيلمًا أو مسلسلًا، ثم حلقة ومصدر فيديو متاحًا.
5. زر «المصادر» أو مفتاح Escape يرجع إلى بطاقات البداية. `Ctrl+1` يرجع للرئيسية.
6. إدارة الإضافات تسمح بإضافة مستودعات أخرى موثوقة. مواقع المصادر قد تتوقف أو تمنع
   شبكة معيّنة؛ رسالة الخطأ ليست دليلًا على نجاح التشغيل.

استخدم فقط المحتوى الذي تملك حق مشاهدته. الإضافات تعمل في عملية JVM منفصلة لكنها
ليست صندوق أمان يمنع الوصول إلى موارد حساب Windows.

## حفظ البيانات والنسخة القديمة
هذه نسخة مستقلة عن LATCHI WATCHING Electron 0.1.2. اسم الاختصار والمجلد:
**LATCHI WATCHING CloudStream**. لا تدّعي الحزمة ترقية Electron أو نقل بياناته.
ملف LATCHI الجديد محفوظ منفصلًا باسم `LATCHI-WATCHING-CloudStream` في بيانات المستخدم.
إلغاء التثبيت يحذف ملفات التطبيق المسجّلة، ويحافظ على ملف المستخدم والملفات التي أضافها.

## التحديثات
التحديث اختياري وبعد موافقة المستخدم. القناة تقبل فقط الإصدارات التي يبدأ وسمها
بـ`watching-cloudstream-v` في `latchidz/LATCHI-RELEASES`، وتطابق اسم الحزمة والبصمة.
إصدارات LATCHI PLAY وIPTV وElectron لا تُعرض كتحديثات لهذا التطبيق.

## حدود الاختبارات
نتائج Windows الفعلية منشورة في `WINDOWS-VERIFICATION.json`. الاختبار الآلي يستخدم
تصييرًا برمجيًا وفيديو محليًا مولّدًا ومخرج صوت افتراضيًا؛ لا يُثبت جودة GPU أو جهاز
الصوت الحقيقي، ولا التشغيل الحي لجميع المواقع. لا يُعلن نجاح مصدر إلا وفق نتيجة اختباره.
